# Tee Asylum+ 扩展版

在原来的随机武器PVP基础上，加入 Item Asylum 风格的24件装备和6种模式。普通DDNet客户端即可连接。装备效果使用DDNet现有锤击、激光、投射物、冻结、击退和音效表现。

## 开始游戏

双击 `Start-TeeAsylum.cmd`，打开DDNet连接 `127.0.0.1:8303`。至少两名玩家进入同一房间才能开始正式比赛。局域网朋友连接服务器电脑的IP加 `:8303`。

按 `1/2/3` 切换槽位，左键使用，滚轮也能切换。特殊模式的槽位内容会随身份变化，以聊天和屏幕装备提示为准。投票菜单可以切换模式、地图、重开比赛，或创建独立房间；默认进入FFA。

当前 `sv_register 0`，服务器不会主动发布到公网列表。公网开服需要自行配置 UDP 8303、防火墙和端口转发。远程管理员密码未固定，请自己设置安全的 `sv_rcon_password`。

## 六种模式

| 模式 | 本版规则 |
|---|---|
| FFA 自由混战 | 每次出生随机近战、远程、特殊各一件；击杀+1，自杀或环境死亡-1；25分或8分钟结算，平分加时。 |
| TDM 团队死斗 | 红蓝两队，队友免伤；团队75分或6分钟结算，平分加时。 |
| GG 武器升级赛 | 槽位1为进阶武器，槽位2急救包、槽位3冲刺；必须用当前进阶武器击杀才升级，共17阶段，最后用“黄金勺”获胜。死亡保留进度；黄金勺使用汤勺外观和强化伤害。 |
| ELIM 三命淘汰 | 每人3命，死亡重抽；每次击杀使生命上限+2、最多20；耗尽命数进入观战。3分钟后开启收缩安全区，圈外每秒损失1生命，最后存活者获胜。 |
| ZS 感染生存 | 随机选初始感染者；生还者死亡变感染者，感染者无限复活。同阵营免伤；感染者用小刀、冲刺、连斩。生还者撑过4分钟获胜，每次新感染延长15秒；全员感染则感染者胜。 |
| JGN 巨人讨伐 | 随机一人巨人，只有1命；生命上限随人数增长，60至200，免击退。挑战者各3命且互相免伤。巨人装备垂死平底锅、英式火箭筒、神圣斗篷；挑战者装备池排除America。巨人被击败或4分钟结束时挑战者胜，挑战者全淘汰则巨人胜。 |

ELIM、ZS、JGN锁定开局名单，中途加入、离开重进或切观战后返回需等待下一局。结束后会自动开始下一局。

## 24件装备

一般角色10生命、2护甲；默认死亡2秒复活、出生保护1秒（攻击解除），弹药无限。FFA有 `7×9×8=504` 种三槽组合。

| 类别 | 装备 |
|---|---|
| 7近战 | 平底锅、小刀、球棒、巨大汤勺、黑心剑、能量剑、垂死平底锅 |
| 9远程 | 左轮、冲锋枪、霰弹枪、电磁炮、榴弹炮、弩、冰冻射线、英式火箭筒、America |
| 8特殊 | 急救包、冲刺汽水、冲击波、破片雷、神圣斗篷、重抽骰子、滑翔伞、连斩 |

新增装备的实际效果：巨大汤勺扩大近战范围并强击退；黑心剑命中敌人回复1生命；能量剑快速4伤害斩击；垂死平底锅向下击退；弩8伤害、远距最多10；冰冻射线1伤害并冻结1秒；英式火箭筒随机2伤软弹或5伤爆炸；America是10伤激光和大后坐力。

神圣斗篷使用后抵挡下一次攻击，破盾后有0.25秒保护，20秒充能；重抽骰子原地重抽、不恢复血甲，玩家级10秒冷却；滑翔伞当前持有时减缓下落，使用可上升；连斩将原作连续斩击合并为前方4伤害、10秒冷却。

参考来源与适配差异见 `CONTENT-ItemAsylum.md`。此次加入的是上述六种模式和十二件新装备；BOSS、MU、TC、KIT、XMAS、VIP尚未实现。Roblox原作三维模型、音乐、动画和全部物品没有导入。

## 配置、源码与恢复

`room_config/modes/asylum*.rcfg` 是六个模式的配置，`room_config/asylum-common.rcfg` 是共用设置。可调整 `scorelimit`、`asylum_round_seconds`、`asylum_lives`、`asylum_respawn_delay`、`asylum_spawn_protection`、`asylum_spawn_armor`，修改后重启服务器。

管理员通过RCON使用 `room_setting 0 asylum_items` 查看装备ID，`room_setting 0 asylum_status` 查看模式状态；`room_setting 0 asylum_loadout 客户端ID 近战ID 远程ID 特殊ID` 可给普通角色指定装备，固定身份和GG不允许覆盖。这不是普通玩家聊天指令。

`DDNet-Server.exe` 与 `TeeAsylum-Server.exe` 是同一个Windows服务器。Linux无扩展名服务器没有重新编译。

原Downloads目录保留 `backup-huntern-original`（最初HunterN）和 `backup-teeasylum-v1`（上一版12装备）。先关闭服务器，再把所需备份的可执行文件和配置复制回原位置即可恢复。源码和测试脚本另附 `TeeAsylum-Expansion-Source.zip`。
